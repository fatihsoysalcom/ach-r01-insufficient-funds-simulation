# ACH R01 Insufficient Funds Simulation

This Python script simulates ACH payment processing, specifically demonstrating the R01 'Insufficient Funds' return code. It includes a basic smart retry mechanism that waits and retries failed payments.

## Language

`python`

## How to Run

Save the code as `ach_r01_simulation.py` and run it from your terminal using: `python ach_r01_simulation.py`
